## 2. 分阶段验收

| 阶段 | 验收标准 |
|---|---|
| ORIS 闭环 | 申请→审核→排台状态逐态正确；排台冲突（同房同日同台次）被拒绝；**缺任一前置核查单时开始手术/离室被服务端拒绝**；完成关档后住院费用清单出现手术费+麻醉费两条明细，退费与出院结算兼容 |
| RIS 闭环 | 护士执行检查医嘱自动生成申请；预约→检查→归档→书写→审核发布逐态正确；**reviewer=reporter 时审核被拒绝**（双签）；发布后医嘱联动"已执行"；危急征象命中自动生成 source=2 危急值并走完闭环；非危急不生成 |
| EMC 闭环 | 分诊四级判定；五大中心登记后节点录入（字典外节点拒绝）；超时节点在详情时间轴中预警；关档后达标率统计数字正确；快速建档患者 EMPI 归一 |
| **三期第二批验收场景** | 住院患者 → 手术申请 → 排台 → 三方核查 → 手术（含麻醉记录）→ 复苏离室 → 关档自动记账；同患者检查医嘱 → 执行 → 预约 → Mock 影像 → 报告双签发布（含危急征象）→ 危急值闭环 → 医生站查报告；急诊分诊（2 级）→ 胸痛中心登记 → 时间节点 → 转收住院 → 关档统计，连续三次成功 |
