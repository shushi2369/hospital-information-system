## 2. 状态机

### 2.1 住院记录（inp_admission.status）

```mermaid
stateDiagram-v2
    [*] --> 在院10: 入院登记(校验无在院记录+分配床位+首笔押金)
    在院10 --> 在院10: 转科(换科室/床位)/补押金/医嘱执行
    在院10 --> 出院未结20: 出院申请(停长期医嘱+费用全部记账)
    出院未结20 --> 已结算30: 出院结算(生成住院收费单+支付+医保申报可选)
    在院10 --> 转院40: 转院(费用结清后)
    已结算30 --> [*]: 生成待归档病案
```

约束：`出院未结` 前置校验——长期医嘱全部停止、检查申请无未收费项、费用记账完成（B6006 阻断）；结算复用一期收费/退费/医保申报。

### 2.2 床位（inp_bed.bed_status）

```mermaid
stateDiagram-v2
    [*] --> 空闲1
    空闲1 --> 占用2: 入院/转科分配
    空闲1 --> 预约3: 预约占床
    预约3 --> 占用2: 患者入院
    预约3 --> 空闲1: 取消预约
    占用2 --> 空闲1: 出院/转科释放
    空闲1 --> 停用4: 维修停用
    停用4 --> 空闲1: 启用
```

并发保护：分配床位 = 条件更新 `SET bed_status=2, current_admission_id=? WHERE id=? AND bed_status=1`，影响行数 0 即 B6001。

### 2.3 医嘱（doc_order.status）

```mermaid
stateDiagram-v2
    [*] --> 待审核10: 医生开立(长期/临时)
    待审核10 --> 审核通过20: 药师审核(药品类)/自动通过(非药品)
    待审核10 --> 已驳回70: 药师驳回(留痕,医生另开)
    待审核10 --> 已作废60: 医生作废
    审核通过20 --> 执行中30: 首条执行/摆药出库
    执行中30 --> 已停止50: 停医嘱(长期)/执行完成(临时)
    已停止50 --> 执行中30: 恢复(当日内)
    审核通过20 --> 已作废60: 作废(未执行部分失效)
    已执行40 --> [*]: 临时医嘱全部执行完成
```

约束：药品类审核通过 + 摆药出库后才可执行（复用库存条件扣减）；皮试医嘱执行通过前，关联药品医嘱不可执行（B6104）。

### 2.4 病历文书（emr_record.status）

```mermaid
stateDiagram-v2
    [*] --> 书写中10: 新建(可套用模板)
    书写中10 --> 已提交20: 提交(必填节校验 B6201)
    已提交20 --> 质控通过30: 质控通过
    已提交20 --> 质控退回40: 质控退回(问题清单)
    质控退回40 --> 已提交20: 修改后重新提交
    质控通过30 --> [*]: 锁定(仅病案归档后只读)
```

### 2.5 病案（mrc_record.archive_status）与医保（medins_settle.status）

```mermaid
stateDiagram-v2
    [*] --> 待归档10: 出院未结时生成
    待归档10 --> 已归档20: 首页质控通过+已结算(双前置)
    已归档20 --> 借阅中30: 借阅登记
    借阅中30 --> 已归档20: 归还
```

```mermaid
stateDiagram-v2
    [*] --> 已申报10: 出院结算后申报(Mock)
    已申报10 --> 对账通过20: 日对账一致
    已申报10 --> 对账差异30: 日对账差异(原因留痕)
    对账差异30 --> 已申报10: 调整后重新申报
```
