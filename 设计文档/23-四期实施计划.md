## 2. 分阶段验收

| 阶段 | 验收标准 |
|---|---|
| 输血闭环 | 申请→审核→配血逐态正确；**不相容配血后发血被硬阻断**；发血须取血人签收；**单人签开始输注被拒**（双人双签门禁）；结束闭环全留痕；不良反应可登记 |
| 耗材批次 | 入库按批次登记；**FEFO 拨发顺序正确**（先到期先出）；跨批次拆分 breakdown 正确；效期 ≤30 天预警标记 |
| CDSS 增强 | type=4 规则：患者过敏史含关键字 + 医嘱含目标药品 → 精确命中；type=3 年龄维度：规则仅对配置年龄段生效 |
| 互认标识 | 发布勾选互认 → 报告查询展示 HR 标签；未勾选不展示 |
| **四期验收场景** | 用血申请 → 配血不相容阻断 → 换袋相容 → 发血签收 → 床边双签输注 → 闭环；耗材两批次 FEFO 领用拆分；过敏映射规则命中；互认标签展示，连续三次成功 |
