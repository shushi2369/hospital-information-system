## 2. 分阶段验收对照

| 阶段 | 验收标准（对齐指导文档 §6 风格） |
|---|---|
| 阶段二·底座+住院（WP2.1~2.2） | 管理员可建病区床位；无在院记录者方可入院；并发抢床只有一个成功；转科后床位状态与费用归属正确；押金/一日清可复核 |
| 阶段二·医嘱+EMR（WP2.3~2.4） | 医生开医嘱→药师审核→摆药出库扣库存→护士执行计费全链贯通；重复执行被拦（B6103）；皮试阳性拦截（B6104）；EMR 必填节校验（B6201）与质控退回重提闭环 |
| 阶段二·护理（WP2.5） | 护士按床号看到待执行单；执行需"核对→执行"两步；体征超范围提示；排班冲突提示 |
| 阶段二·病案+医保（WP2.6~2.7） | 出院未结自动生成待归档病案；未结算/质控未通过均不可归档（B6301/B6302）；结算后医保申报 Mock 对账闭环 |
| **最终验收场景（§9 风格）** | 门诊医生开住院证 → 入院登记（床位+押金）→ 医生开长期/临时医嘱 → 药师审核+摆药 → 护士核对执行（含皮试）→ 一日清核对 → 出院申请 → 出院结算（押金抵扣+补缴）→ 病案首页编码质控归档 → 医保申报对账 → 全程日志可查，**连续三次成功**且金额/库存/状态一致 |
