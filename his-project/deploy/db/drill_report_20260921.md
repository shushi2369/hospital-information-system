## 三、渗透自查（API 级，攻击者视角清单）

| 项 | 结果 |
|---|---|
| Mass Assignment（请求体注入 status/id/chargeStatus/version/createdAt） | **防住**：DTO 白名单，注入字段全部忽略，实际状态仍为待审核 10 |
| 错误信息泄露（单引号注入 / 超长数字 ID） | **防住**：统一返回"请求体格式错误"+traceId，无堆栈/SQL 片段 |
| SQL 注入 | 防住（MyBatis-Plus 参数化，历史核查） |
| 登录暴力破解 | 防住（Redis 失败限流 + A0007） |
| HTTP 方法滥用 | 防住（写操作全为 POST/PUT，GET 只读——历史核对） |
| XSS | 防住（无 v-html，Vue 转义——历史核对） |

**登记**：正式渗透报告（等保三级）仍需外部测评机构出具；生产启动前必须设置 `JWT_SECRET` 环境变量（当前为 dev-only 默认值）。
