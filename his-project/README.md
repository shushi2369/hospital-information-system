## 开源说明与免责声明

- 本项目是**教学用途的医院信息系统模拟实现**（求职作品集 + 课程配套实验），所有数据均为合成演示数据，不含任何真实患者信息（PHI）。
- **请勿用于真实医疗场景**：未经过医疗行业合规评审（电子病历规范、等保、数据安全法等），也无临床可靠性保障。
- 演示账号与密钥（`His@2026`、`dev-only-*`、AES 占位密钥）仅为本地教学便利而硬编码，部署到任何可被外部访问的环境前**必须全部更换**。
