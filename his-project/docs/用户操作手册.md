# HIS 一期用户操作手册

版本：V1.0 ｜ 适用：医院信息系统一期（阶段一~四全部功能）

## 1. 登录与通用操作

1. 打开系统地址（本地开发 `http://localhost:5173`，容器化部署 `http://<服务器IP>/`）。
2. 输入用户名与密码登录。初始密码由管理员发放；首次登录建议立即修改（右上角头像 → 修改密码）。
3. 左侧菜单按角色自动显示，**看不到的菜单即该角色无权使用**；直接调用无权接口也会被拒绝并提示"无权访问该功能"。
4. 会话 30 分钟无操作自动过期，重新登录即可。连续输错密码 5 次将临时锁定 1 分钟。
5. 通用提示：红色弹窗为错误原因（如"库存不足"），按提示处理即可；所有提交按钮已做防重复点击。

## 2. 管理员操作

### 2.1 基础资料（必须先行配置）

- **机构信息**：维护医院名称、地址、电话。
- **科室管理**：新增科室并选择类型（临床科室/医技科室/药房/收费挂号），填写位置。挂号只可选"临床科室"。
- **医生管理**：新增医生须先在"用户管理"创建其登录账号；绑定账号、科室、职称、是否专家、挂号费（普通/专家）与每日号源（上午/下午各限额）。
- **药品管理**：药品编码、规格、零售价、库存预警下限；停用后不可新开处方。
- **收费项目**：挂号费/诊查费/检查费/检验费/治疗费/材料费/药品费七类；检查检验申请只可选检查费、检验费类项目。
- 注意：基础资料**没有删除**，只有"停用"。已被业务引用的记录停用后历史单据不受影响。

### 2.2 用户与角色

- 用户管理：创建账号（初始密码 8~32 位）、绑定角色、重置密码、停用启用（禁用即时踢下线）。
- 角色管理：内置五角色不建议修改；如需自定义角色，勾选菜单树后保存。权限即改即生效（该角色用户重新登录后菜单刷新）。

### 2.3 日志查询

- 操作日志：按人/模块/单号/日期查询所有关键操作（含失败操作与原因），身份证、手机号已脱敏。
- 登录日志：登录成功/失败记录，用于安全审查。

## 3. 收费员操作（挂号收费）

### 3.1 患者建档

1. 挂号收费 → 患者建档 → "新建档案"：姓名、性别、出生日期、**身份证号（18 位）、手机号**必填，过敏史/既往史建议完整填写（医生站会红字提示）。
2. 同一身份证重复建档会被拦截，并提示已有建档号——请直接使用原档案。
3. 卡片遗失用"补办就诊卡"生成新卡号，旧卡自动不再使用。

### 3.2 挂号与退号

1. 挂号管理 → 现场挂号：搜索选择患者 → 选科室、医生（专家号只显示专家医生）→ 选日期与上午/下午 → 号别。系统自动分配排队号并显示费用合计（挂号费+诊查费）。
2. 同一患者同一时段同一医生已有有效挂号时会提示"请勿重复挂号"；号源满时提示"号源已满"。
3. 退号：仅"已挂号"状态可退。**退号不自动退费**——若挂号费已收，请在收费结算页办理退费（已完成就诊的挂号费/诊查费不可退）。

### 3.3 收费

1. 收费结算 → 左侧"未收费就诊"列表点击患者 → 右侧显示待缴费明细（挂号费、诊查费、药品、检查检验，逐行来自处方与申请单，金额由系统计算）→ 选择支付方式 → 确认收费。
2. 收费成功生成收费单号；一张就诊单只收一次费。
3. **退费**：在收费记录中打开单据详情 → 勾选要退的明细行并填退数量、原因。规则：
   - 药品费必须**整方退**（该处方全部明细一起退）；
   - 已发药的处方须先到药房办理退药，再来退费；
   - 已完成就诊的挂号费/诊查费不可退；
   - 退费即时生效并保留原单记录。

### 3.4 日结

- 收费结算 → 日结页签 → 选择日期（默认今天）→ 执行日结。系统汇总本人当日收费单数/退费单数/金额并锁定，同一天不能重复日结；金额可与收入明细逐笔核对。

## 4. 医生操作（医生工作站）

1. 候诊队列：显示本人当日候诊患者（按排队号）。点"接诊"进入就诊工作台。
2. 工作台：
   - 顶部患者条含**过敏史红字提示**，请务必核对。
   - **病历**页签：填写主诉、现病史、体格检查、处理意见，可多次"暂存"。
   - **诊断**页签：新增诊断（第一条自动为主诊断），可删除重加。
   - **处方**页签：新开处方逐行添加药品（名称/规格/价格为字典价），填写单次剂量、频次、用法、天数、数量；金额由系统计算。未审核/未收费未发药的处方可"作废"。
   - **检查/检验**页签：从收费项目字典选择检查或检验项目开申请单。
   - 全部完成后点右上角"**提交病历**"——系统校验主诉/现病史/诊断齐全；**提交后整单只读**，如需更正请重新挂号就诊。
3. 处方流转：开方后由药师审核 → 患者缴费 → 药房发药；驳回的处方请另开新处方（原处方留痕）。

## 5. 药师操作（药房工作台）

1. **处方审核**：逐方核对药品、剂量、用法、配伍，"通过"或"驳回"（意见必填，驳回后医生需另开）。审核通过的处方待患者缴费后进入可发药队列。
2. **发药**：可发药队列 = 审核通过 + 已收费。点"发药"系统自动按"效期先近先出"扣减库存批次；库存不足或批次过期会被拒绝并提示缺口。
3. **退药**：在发药记录中对已发药处方办理**整方退药**（原因必填），库存自动回补；随后通知收费员办理药品费退费。已退药的处方自动作废，不能重复发药或重复退药。
4. **库存管理**：
   - 入库：选药品、批号、失效日期（不允许过期品入库）、数量；
   - 库存预警：可用量 ≤ 预警下限的药品自动列入预警页签，红色标注；
   - 出入库流水：全部库存变动可按药品或单号追溯。

## 6. 对账员操作（只读）

- 挂号记录、收费/退费单据、日结记录均为只读查询，用于财务复核；
- 统计报表：日挂号量、日门诊量、日收入（含费用类别分布）、收入明细（可导出 CSV，Excel 可直接打开）、药品库存汇总；
- 发现差异时以收入明细与收费单明细逐笔核对，异常通过操作日志追溯到具体操作人与时间。

## 7. 二期功能（住院闭环）

二期新增住院相关功能与角色（护士 nurse.wang/nurse.liu、病案员 mrc.zhou、医保专员 yb.sun）：

### 7.1 收费员：住院管理
- **入院登记**：选择患者 → 科室→病区→空闲床位（联动）→ 主治医生 → 首笔押金（必缴）。同一患者已有在院/待结算记录时不能重复入院。
- **床位管理**：床位卡片四色显示（空闲/占用/预约/停用）；占用床必须出院或转科后才能再分配。
- **押金**：在院患者可多次补缴，金额原子累加；押金只增不减。
- **一日清**：按日期展示住院费用明细（床位费每日自动记账、医嘱执行/摆药即时记账）。
- **出院结算**：医生发出院申请后，住院进入"出院未结"；收费员执行结算生成住院收费单（金额=未结一日清合计，押金另行提示抵扣）。

### 7.2 医生：住院医嘱与 EMR
- **开医嘱**：长期（qd/bid/tid/q8h 频次自动生成每日执行计划）或临时；药品类需药师审核并摆药后护士才能执行；需皮试的医嘱先登记皮试结果（阳性自动作废）。
- **停嘱**：出院前必须停止全部长期医嘱，否则出院申请被系统阻断。
- **EMR**：新建文书（可套模板）→ 按节书写 → 提交（缺必填节会被拦截并提示节名）→ 质控通过后锁定。

### 7.3 护士：护理工作台
- **执行单**：按床号显示当日待执行医嘱；逐条"执行"（执行即计费）；皮试行登记"阴性/阳性"。
- **体征**：录入体温/脉搏/呼吸/血压等（超范围会被拦截），可查询历史（体温单数据）。
- **排班**：护士长按日排班（同一护士同日仅一条）。

### 7.4 病案员：病案管理
出院未结的住院自动进入"待归档"病案；流程：**首页编码（ICD-10 远程搜索）→ 首页质控通过 → 归档**（未结算或质控未通过均不可归档）；已归档病案可借阅/归还。

### 7.5 医保专员：医保对账
出院结算后的账单可申报医保（Mock 网关自动拆分统筹/个账/自费）；每日对账，差异留痕；同一账单只能申报一次。

## 8. 密码与账号安全

- 所有内置账号初始密码为 `His@2026`；**登录后请立即修改**（右上角头像 → 修改密码）。
- 密码以单向加密存储，忘记无法找回，只能重置：
  - 普通账号：管理员在"用户管理"中重置；
  - 管理员本人遗忘：用数据库管理员执行
    `UPDATE sys_user SET password_hash='INIT:His@2026' WHERE username='admin';`
    然后重启后端服务（Windows：`net stop HIS-Backend && net start HIS-Backend`），即恢复初始密码。
- 演示账号仅存在于加载了演示数据的环境；生产环境只有 admin 账号。

## 9. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示"未登录或登录已过期" | 会话过期，重新登录 |
| 提示"无权访问该功能" | 角色无此权限，找管理员确认授权 |
| 挂号提示"号源已满" | 该医生该时段名额已满，换时段/医生或次日再挂 |
| 发药提示"库存不足" | 按提示缺口先入库，再发药 |
| 退费提示"处方药品费须整方退费" | 勾选该处方全部明细一起退 |
| 退费提示"已发药，请先到药房退药" | 先到药房整方退药，再办退费 |
| 病历无法修改 | 就诊已提交完成；如需更正，重新挂号就诊 |
