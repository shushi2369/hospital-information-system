# 教案 · 基础篇（课时 1~4）

## 课时 1：HIS 总览与系统架构

**教学目标**：说清 HIS 的业务版图与本项目架构；完成环境部署。
**重点**：模块化单体的边界（app 层）；**难点**：为什么不做微服务。

### 课堂流程
1. 讲授（30′）：医院信息化版图（HIS/LIS/PACS/EMR 的关系）→ 本系统 18 模块地图 → 分层架构图（nginx → Spring Boot 单体 → MySQL/Redis）。强调 **app 层防腐**：跨模块读写只经 InpAppService/ClinicAppService 等，模块间不直连 mapper——这是"今天的单体、明天的微服务"。
2. 演示（20′）：`bash deploy/deploy.sh` 全流程——停服→备份→替换→健康检查→Flyway 校验→前端产物回收。打开 `http://localhost/` 登录 admin。
3. 实验（40′）：实验 E0 前半——跑通登录，用 `/auth/me` 看自己的角色与权限集。

### 检查点
- [ ] deploy.sh 六步全部通过，健康检查 200
- [ ] 能说出"为什么状态机变更收敛在 app 层"

### 作业
阅读 `docs/portfolio/系统设计白皮书.md` §3，画一张你理解的部署图。

## 课时 2：RBAC 权限模型与动态菜单

**教学目标**：掌握 用户-角色-权限 三层模型与前端/后端双重校验。
**重点**：@PreAuthorize 是唯一防线；**难点**：数据范围（横向）vs 功能权限（垂直）。

### 课堂流程
1. 讲授：sys_user/sys_role/sys_menu 三表模型 → 登录后 JWT → 前端按权限生成动态菜单、v-perm 隐藏按钮（体验层）→ 后端 @PreAuthorize 逐端点校验（防线）。267 端点覆盖率 100%（扫描器审计）。
2. 演示：用 cashier.li 登录——看不到"系统管理"菜单；直接调 `GET /api/v1/system/users` → A0003。
3. 实验（40′）：**实验 E0**——逐角色登录，填权限矩阵表（能否建档/收费/发药/看日志），与系统实际比对。

### 检查点
- [ ] 能解释"前端隐藏按钮为什么不是安全边界"
- [ ] 权限矩阵 10 角色 × 8 功能填写完成

## 课时 3：患者主索引与 PHI 脱敏

**教学目标**：理解 EMPI 概念与隐私保护的工程实现。
**重点**：身份证哈希查重；**难点**：脱敏层次（服务端统一 vs 前端点缀）。

### 课堂流程
1. 讲授：主索引（MPI）为什么是 HIS 的地基（一人多卡、合并分裂）→ PHI 合规要求 → 本系统双层脱敏：服务端 `toResponse()` 统一打码（手机 3+4、身份证 4+4）+ `id_card_hash` 哈希列查重 + 前端 mask.ts 二道防线。
2. 演示：同一身份证建两次档 → B1001；列表页手机号显示 `138****`；`GET /patients` 响应里看不到明文。
3. 实验（40′）：**实验 E1**——建档/重复建档/按前缀搜电话/查看详情脱敏一致性。

### 检查点
- [ ] 说出服务端脱敏比前端脱敏强在哪（导出/接口层无法绕过）
- [ ] 触发一次 B1001 并解释查重用的哪一列（哈希列，不是原文列）

## 课时 4：业务状态机——以就诊为主线

**教学目标**：建立"状态机+三层防线"的核心思维。
**重点**：前态校验/条件更新/唯一索引；**难点**：为什么三层都要。

### 课堂流程
1. 讲授：就诊状态 10 候诊 →20 就诊中 →30 已完成；住院/手术/危急值各链对比。三层防线逐一拆解：前态校验（防跳步）、条件更新（`UPDATE ... WHERE status=旧值`，影响行数判定，并发双击一人成功）、唯一索引（预检窗口的竞态兜底，DuplicateKeyException 转业务码）。
2. 演示：两个浏览器同时点"接诊"同一挂号单；或并发重复收费撞 `uk_bill_visit`。
3. 实验（40′）：**实验 E2**——按合法顺序推进就诊状态，再故意跳步/重复，记录每个错误码。

### 检查点
- [ ] 画出就诊状态机图并标注每条边的 API
- [ ] 说出三层防线各自拦哪类并发场景
