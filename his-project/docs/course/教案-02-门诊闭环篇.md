# 教案 · 门诊闭环篇（课时 5~8）

> 主线：挂号 → 接诊 → 处方 → 审核 → 收费 → 发药。每个环节的"门禁"都是教学点。

## 课时 5：挂号-接诊-处方开立

**教学目标**：跑通门诊前三环；理解处方明细的价格快照设计。
**重点**：就诊号贯穿全链；**难点**：快照与调价的向后兼容。

### 课堂流程
1. 讲授：挂号单→就诊单一对一；处方开立的校验（库存/用法）；**明细快照**——保存开立时刻药品名与单价，调价不影响历史处方打印与退费。
2. 演示：挂号（cashier.li）→ 接诊（dr.li）→ 开处方（含药 + 检查申请）。SQL 对照：`cli_prescription_item` 里的快照字段。
3. 实验：实验 E5 的前置三步（挂-接-开），记录每步返回的单号前缀（JZ 号 / 处方号）。

### 检查点
- [ ] 说出就诊号、挂号单 ID、就诊单 ID 三者的关系
- [ ] 解释"为什么退费要按快照价退"

## 课时 6：药学审核与发药（含 FEFO）

**教学目标**：掌握处方状态机与药房门禁；理解批次/效期管理。
**重点**：审核门禁与重复操作拦截；**难点**：FEFO 的并发扣减。

### 课堂流程
1. 讲授：处方 10 待审 →20 已审 →30 已发药 →50 作废；药师审核（B4008 重复审核拦截）→ 发药（B4003 重复发药拦截）→ 未审核不能发药。药库 FEFO：批次维度库存、效期升序拣货、行锁+条件更新防超卖（C1-C3 并发断言）。
2. 演示：发药后尝试退费（须按整方数量勾选药费行——部分数量先撞 B3003 整方闸门） → B3004"已发药，请先到药房退药"；退药后才能整方退费。
3. 实验：**实验 E3**——审核→发药→重复发药拦截→退药→退费全流程。

### 检查点
- [ ] 完整复述处方状态机与每条边的拦截码（B4008/B4003/B3004）
- [ ] 解释 FEFO 为什么能降效期报废

## 课时 7：收费、退费与幂等

**教学目标**：掌握资金路径的三道防线与退费规则集。
**重点**：幂等三段式；**难点**：整方退/已发药先退药/挂号费时限的规则组合。

### 课堂流程
1. 讲授：@Idempotent 切面（SETNX+摘要+快照+失败释放+fail-open）；收费唯一索引兜底（并发双收银员一人成功）；退费规则集——明细余量（B3003）、整方退（B3003）、已发药先退药（B3004）、就诊开始后挂号费不可退（B3005）；退费行锁。
2. 演示：同一 idempotency key 重放收费 → 返回首次响应；换 body 重放 → A0005。
3. 实验：**实验 E4**——幂等重放 ×2 场景 + 退费规则逐条触发。

### 检查点
- [ ] 触发并解释 A0004/A0005/B3003/B3004/B3005
- [ ] 画出"收费→退费"的账单状态变化（10→20 部分→30 全退）

## 课时 8：综合实验——门诊全链路（E5）

**教学目标**：无指导跑通 门诊→处方→收费→发药→部分退费→退药→全退 闭环。
**形式**：实验 E5，只给验收检查点（12 项），不给步骤。教师用 `consistency_check.sql` 当堂验证无脏数据。
**检查点**：见实验手册 E5；附加挑战——用两个浏览器窗口制造并发双收费冲突并解释结果。
