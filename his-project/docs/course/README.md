# HIS 教学课程总纲

> 以真实运行的医院信息系统为教具的教学课程。所有演示和实验都在本仓库系统上可复现，教学深度对齐岗位实战。

## 课程信息

- **适用对象**：医疗信息化方向本科生 / 转行培训 / 初级工程师
- **先修要求**：基础 Java 或 Python、了解 HTTP 与 SQL；医学背景不是必需
- **课时安排**：16 课时 × 90 分钟（讲授 30′ + 演示 20′ + 实验40′）
- **考核建议**：实验完成度 50% + 综合实验（E10 门诊-住院全链路）30% + 期末问答（从《面试问答》题库抽题改造）20%

## 教学法说明

1. **每个概念都有三个锚点**：真实页面（学生点得到）→ API 报文（实验手册可复制）→ 数据库行（SQL 可查证）。三者对照是本课程的核心训练。
2. **错误码是主角**：故意触发 B1001/B3001/B3003/B3006/B6002 等拦截，让学生从"报错"学到"规则"。
3. **回归文化**：每次实验完成后跑一遍 `e2e_acceptance.py`，让学生看到"我的操作没有破坏系统"——把回归思维教进肌肉记忆。
4. **红线**：所有实验在测试库进行；教学密码仅限内网演示环境。
