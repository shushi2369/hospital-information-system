# 教案 · 专科与质量篇（课时 13~16）

## 课时 13：检验危急值与 RIS 闭环

**教学目标**：掌握危急值四步闭环与闭环率指标。
**重点**：状态只能沿链推进；**难点**：阈值治理（过频麻木/过疏失效）。

### 课堂流程
1. 讲授：十八项核心制度背景 → 待处理→已通知（技师）→已确认（医生）→已闭环（处置意见）四步；阈值按项目+年龄组维护；超时升级；闭环率/平均通知时长/平均确认时长三指标。RIS 侧：检查申请→预约→登记→写报告→审核发布，与 LIS 同构对照。
2. 演示：lab.chen 登记通知 → dr.li 确认 → 闭环 → 达标统计页看闭环率。
3. 实验：**实验 E9**——完整闭环一条危急值 + SQL 验证四态时间戳。

### 检查点
- [ ] 触发跳步操作并解释为何被拒
- [ ] 说出闭环率为什么能进科室考核

## 课时 14：急诊五大中心时间轴

**教学目标**：理解"录入即质控"的时间轴设计。
**重点**：节点四重校验；**难点**：时间基准（登记时刻截断到秒）。

### 课堂流程
1. 讲授：五大中心政策背景与考核时限（大门→首份心电图 ≤10min、大门→球囊 ≤90min）；分诊→救治登记（一对一唯一索引防重复）→节点录入→达标判定→达标率统计；节点字典可配置（认证标准调整不改代码）。
2. 演示：emc.li 分诊（绿色通道）→ 中心登记 → 录 XT_ECG 节点 → 时间轴抽屉看"达标/超时"标签 → 达标统计页。
3. 实验：跑一条胸痛病例全流程，故意录入跨中心节点/重复节点/早于登记时刻的节点，记录三次拦截。

### 检查点
- [ ] 说出节点录入的四重校验
- [ ] 解释"达标率"如何按中心/节点/月聚合

## 课时 15：输血科闭环

**教学目标**：掌握用血申请到输注结束的强门禁链。
**重点**：血型/交叉配血相容性；**难点**：双人双签与状态门禁的组合。

### 课堂流程
1. 讲授：申请 XY→审核→交叉配血（血型/成分不匹配拦截）→发血（不相容硬阻断、取血护士签收 30→40）→输注开始（双人双签，同签人拦截，40→50）→不良反应登记→结束闭环（50→60）；血袋状态与请求状态双线；废血/退血通道。
2. 演示：用血申请由 dr.li 发起、bb.tech 审核/配血/发血、输注与结束由护士；故意用不相容血袋发血 → 硬阻断。
3. 实验：完整走一台输血闭环 + SQL 查 `bb_blood_bag.status` 与 `bb_request` 的时间线留痕（配血 2 + 发血 1 + 输注 1 + 不良反应 1）。

### 检查点
- [ ] 画出输血双状态机（请求态 × 血袋态）
- [ ] 解释闭环聚合留痕如何支撑追溯

## 课时 16：质量工程专题——并发/越权/降级/CI

**教学目标**：把"质量是跑出来的"方法论教给学生。
**重点**：回归固化与审计自动化；**难点**：设计并发测试用例的思路。

### 课堂流程
1. 讲授（40′）：50+ 轮查验方法论——每轮聚焦一个子系统，产出修复+模式沉淀+回归脚本。四个标志性案例：
   - **并发**：同患者并发双入院恰一笔成功（患者行锁）、同袋并发发血（唯一约束）；
   - **越权**：267 端点 @PreAuthorize 扫描 + billDetail 裸查 IDOR（列表过滤≠详情过滤）；
   - **降级**：Redis 停机七探针演练（认证单点、fail-open/fail-closed 逐触点定性）；
   - **对账**：75 段一致性巡检作为发布门禁。
2. 演示（20′）：跑 `concurrency_test.py` 24 项并发断言；跑端点清点（`grep -rEc "@(Get|Post|Put|Delete|Patch)Mapping" his-backend/src/main/java/com/his/modules --include="*Controller.java"`）看覆盖率。
3. 实验（30′）：学生任选一个此前实验的"重复操作/并发场景"，仿照 `concurrency_test.py` 写一条并发断言并跑通。
4. 布置综合实验 **E10**（期末）：门诊-住院-手术全链路 + 当堂答辩。

### 检查点
- [ ] 说出并发用例设计的三个要素（共享资源、竞态窗口、终态断言）
- [ ] 完成一条自定义并发测试
