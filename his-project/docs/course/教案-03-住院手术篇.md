# 教案 · 住院与手术篇（课时 9~12）

## 课时 9：住院管理——入院到出院

**教学目标**：掌握住院状态机（10 在院→20 出院未结→30 已结算）与一日清。
**重点**：转科转床的原子性；**难点**：出院门禁（未完结手术拦截 B6006）。

### 课堂流程
1. 讲授：入院登记（同患者在院唯一）→ 床位占用 → 一日清自动计费（医嘱执行/护理/床位费）+ 手工记账通道 → 转科转床一个事务三动作 → 出院门禁（未完结检查/手术 → B6006）→ 零费出院自动结算。
2. 演示：入院 → 手工记账一笔 → 出院 → 出院未结清单出现 → 稍后再看零费场景的自动结算。
3. 实验：**实验 E6**——住院全周期 + SQL 验证 `inp_daily_fee.charge_status`。

### 检查点
- [ ] 说出住院三状态与每条的 API
- [ ] 触发 B6006 并处理掉未完结项完成出院

## 课时 10：医嘱闭环与执行单

**教学目标**：理解医嘱-执行单两层模型与 L/P 联动。
**重点**：执行单条件更新（并发执行一人成功）；**难点**：执行→LIS/RIS 申请自动联动。

### 课堂流程
1. 讲授：医生开医嘱 → 生成执行单（护士视角 todo 队列）→ 执行（单赢家条件更新，重复执行拦截）→ 检验类执行自动生成 LIS 申请、检查类联动 RIS。执行单唯一约束 `uk_exec(item, date, slot, type)` 防重复生成。
2. 演示：开检验医嘱 → 护士执行 → lab.chen 视角出现待采集标本 → 采集（条码）→ 接收 → 录结果 → 发布。
3. 实验：跟做一遍 LIS 短链路，SQL 对照 `doc_order_exec.status` 与 `lis_request.status`。

### 检查点
- [ ] 解释"医嘱"与"执行单"为什么分层
- [ ] 说出执行单并发推进用的机制（条件更新 + 唯一约束）

## 课时 11：手术排台与安全核查

**教学目标**：掌握手术七状态机与三道门禁。
**重点**：槽位唯一约束；**难点**：核查双签与"麻醉前核查未登记不能开始"。

### 课堂流程
1. 讲授：申请 10→审核 20→排台 30→术中 40→复苏 50→完成 60（取消 70）；排台（room,date,seq）唯一索引 `uk_schedule_slot2`，撞槽 B6002；完成/取消释放槽位可重排；WHO 三时点核查单逐项勾选 + 双人不同签；关档自动记账。
2. 演示：排台同一槽位两次 → 第二次 B6002；核查未登记点"开始" → 拦截。
3. 实验：**实验 E7**——制造槽位冲突并排开；完成一台手术后重排同槽位。

### 检查点
- [ ] 说出槽位三元组与释放条件
- [ ] 解释为什么核查门禁放在后端而不是只放前端提示

## 课时 12：出院结算与日结（资金正确性专题）

**教学目标**：理解结算的"标记收窄+残留复查"与日结锁定。
**重点**：对账思想；**难点**：为什么日结后要锁定当日交易。

### 课堂流程
1. 讲授：出院结算 = 未结费用清单→账单（`uk_bill_adm` 防双结算）→**标记收窄**（只标记账单包含的费用 ID）→**残留复查**（有新增费用即回滚重试）——防"结算窗口期新增费用被标记已结却从未入账单"的资损。日结 `(日期,收费员)` 唯一 + **锁定语义**（本人当日已日结后拒绝再收费/退费，B3006）——否则交易游离于所有日结之外，对账永久失真。
2. 演示：结算一笔住院 → 日结 → 再尝试收费 → B3006 → 切换账号继续收。
3. 实验：**实验 E8**——结算+日结+锁定三连；用巡检 SQL 验证"汇总=明细"。

### 检查点
- [ ] 复述"读清单后按父 ID 全量标记"为什么是资损模式
- [ ] 用一条 SQL 从明细重算日结金额并比对
