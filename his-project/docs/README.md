## 维护规范（强约定）

1. **变更日志**：每轮修复/功能变更在 `CHANGELOG.md` 顶部追加一节（日期 + commit + 要点），README 不再堆积修复明细。
2. **索引同步**：新增文档必须在本索引登记；删除文档必须清理所有引用它的链接。
3. **一次性报告**：演练报告、检查报告、压测报告产出后，把长期有效的结论并入 runbook/README，原文件删除（结论已在 git 历史可查）。
4. **私人文档**：简历/面试材料/账号密码等一律放本目录之外且加入 `.gitignore`，严禁提交。
